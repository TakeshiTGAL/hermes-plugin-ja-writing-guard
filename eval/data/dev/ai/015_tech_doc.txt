## セットアップ

### 必要な環境

- Node.js 20 以上
- npm 10 以上（または pnpm 9 以上）
- Git

Node.js のバージョンは、以下のコマンドで確認できます。

```bash
node -v
```

### インストール

グローバルにインストールする場合は、次のコマンドを実行してください。

```bash
npm install -g kumo-cli
```

プロジェクト単位で使いたい場合は、開発依存としてインストールすることもできます。

```bash
npm install --save-dev kumo-cli
```

### 初期設定

インストールが完了したら、プロジェクトのルートディレクトリで初期化コマンドを実行します。

```bash
kumo init
```

対話形式でいくつか質問されるので、画面の指示に従って回答してください。完了すると、ルートに `kumo.config.json` が作成されます。

### 動作確認

以下のコマンドでバージョンが表示されれば、セットアップは完了です。

```bash
kumo --version
```

### トラブルシューティング

**`command not found: kumo` と表示される場合**

npm のグローバルインストール先が `PATH` に含まれていない可能性があります。`npm config get prefix` で表示されたディレクトリの `bin` を `PATH` に追加してください。

**`EACCES` エラーでインストールに失敗する場合**

グローバルディレクトリへの書き込み権限がありません。`sudo` を使うのではなく、nvm などのバージョンマネージャーで Node.js をインストールし直すことをおすすめします。
