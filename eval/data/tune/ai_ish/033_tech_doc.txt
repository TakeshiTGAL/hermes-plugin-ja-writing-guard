# 開発環境セットアップガイド

このガイドでは、社内勤怠システムの開発環境を構築する手順を、ステップバイステップでわかりやすく解説します。初めての方でも安心して進められるよう、一つひとつ丁寧に説明していきますので、ぜひ最後までお付き合いください！

## 📋 前提条件

始める前に、以下のツールがインストールされていることを確認しましょう。

- Node.js（v20以上）
- Docker
- Git

## ステップ1：リポジトリをクローンする

まずは、リポジトリを手元にクローンします。

```bash
git clone git@example.internal:attendance/app.git
cd app
```

## ステップ2：依存パッケージをインストールする

次に、必要なパッケージをインストールします。

```bash
npm install
```

## ステップ3：環境変数を設定する

`.env.example` をコピーして `.env` を作成します。

```bash
cp .env.example .env
```

## ステップ4：データベースを起動する

Docker を使ってデータベースを起動します。

```bash
docker compose up -d
```

## ステップ5：開発サーバーを起動する

最後に、開発サーバーを起動しましょう。

```bash
npm run dev
```

ブラウザで `http://localhost:3000` にアクセスし、ログイン画面が表示されれば成功です！

## 🎉 おめでとうございます！

これで開発環境のセットアップは完了です！お疲れさまでした。

途中でエラーが発生した場合は、慌てずにエラーメッセージを確認してみてください。それでも解決しない場合は、遠慮なくチームメンバーに相談しましょう。Happy coding! 🚀
