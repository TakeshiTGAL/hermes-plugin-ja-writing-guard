# logsieve

**logsieve** は、大量のログファイルから必要な情報を素早く抽出するための、軽量かつ強力なコマンドラインツールです。🚀

## ✨ 特徴

- **⚡ 高速な処理**：Rust製のエンジンにより、数GBのログファイルも数秒で解析できます。
- **🔍 柔軟なフィルタリング**：正規表現、時間範囲、ログレベルなど、多彩な条件を組み合わせて検索できます。
- **🧩 シームレスな統合**：既存のシェルスクリプトやCI/CDパイプラインにシームレスに組み込むことができます。
- **🎨 見やすい出力**：カラー表示やJSON出力に対応し、人にも機械にも優しい設計です。

## 🎯 なぜ logsieve なのか？

ログ解析は、障害対応やパフォーマンス改善において欠かせない作業です。しかし、grep や awk を組み合わせた従来の方法では、複雑な条件の指定が難しく、時間がかかってしまうことも少なくありません。

logsieve は、こうした課題を解決し、開発者がより本質的な作業に集中できるよう設計されています。シンプルなインターフェースでありながら、高度なユースケースにも対応できる柔軟性を兼ね備えています。

## 📦 インストール

```bash
cargo install logsieve
```
