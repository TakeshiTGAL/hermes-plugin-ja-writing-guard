## コントリビューションについて

このプロジェクトに興味を持っていただき、ありがとうございます。あなたの貢献を心から歓迎します！

### Issue を立てる前に
- 同じ内容の Issue がすでにないか、検索してから立ててください。
- バグ報告には、再現手順、期待した動作、実際の動作、使っているバージョン（`kanaform --version` の出力）を書いてください。

### Pull Request の出し方
1. `main` から作業用のブランチを切ってください。ブランチ名は `fix/〜` か `feat/〜` で始めます。
2. 変更には、可能な限りテストを付けてください。テストは `npm test` で実行できます。
3. コミットメッセージは日本語でも英語でも構いません。
4. 大きな変更（新しいオプションの追加や、出力形式の変更など）は、先に Issue で相談してもらえると、レビューがスムーズです。

### レビューについて
メンテナは2名で、業務の合間に見ているため、最初の返信まで1週間ほどかかることがあります。2週間たっても反応がない場合は、Issue か PR にコメントで声をかけてください。

### 行動規範
参加者全員が、互いに敬意を持って接することを期待します。
