# 新入社員向け 開発環境セットアップ手順書

## はじめに

本手順書では、新しく入社されたエンジニアの皆さまが、スムーズに開発をスタートできるよう、開発環境のセットアップ方法をステップバイステップで詳しく解説します。

## 📋 前提条件

- **会社支給のMacBook**を使用していること
- **社内アカウント**が発行済みであること

## ステップ1：Homebrewのインストール

まずは、macOS用のパッケージ管理ツールであるHomebrewをインストールしましょう。ターミナルを開き、公式サイトに記載されているインストールコマンドを実行してください。

## ステップ2：必要なツールのインストール

次に、開発に必要なツールを一括でインストールします。

```bash
brew install git node@20 postgresql@16
```

## ステップ3：リポジトリのクローン

```bash
git clone git@github.com:example-corp/order-app.git
cd order-app
```

## ステップ4：依存関係のインストールと起動

```bash
npm install
npm run dev
```

ブラウザで `http://localhost:3000` にアクセスし、画面が表示されれば成功です🎉

> ⚠️ **注意**: エラーが発生した場合は、慌てずにエラーメッセージをよく確認しましょう。多くの場合、解決策はエラーメッセージの中に隠されています。

## おわりに

以上で開発環境のセットアップは完了です！お疲れさまでした！
不明な点があれば、遠慮なくチームメンバーに質問してくださいね。一緒に素晴らしいプロダクトを作っていきましょう！💪
