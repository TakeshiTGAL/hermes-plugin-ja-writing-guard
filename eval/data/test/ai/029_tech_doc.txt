# rowmatch

2つのCSVファイルを、キー列をもとに行単位で比較するコマンドラインツールです。行の並び順が違っていても、同じキーを持つ行どうしを突き合わせて、追加・削除・変更された行を出力します。

## インストール

```
pip install rowmatch
```

Python 3.10 以上が必要です。

## 使い方

```
rowmatch old.csv new.csv --key id
```

キー列が複数ある場合は、カンマで区切って指定します。

```
rowmatch old.csv new.csv --key store_code,item_code
```

出力は次の形式です。

```
+ 追加: id=1043
- 削除: id=0871
~ 変更: id=0912  price: 1200 -> 1350
```

## オプション

| オプション | 説明 |
|---|---|
| `--key` | 突き合わせに使う列名（必須） |
| `--ignore` | 比較から除外する列名（カンマ区切り） |
| `--encoding` | 入力ファイルの文字コード（既定は utf-8。cp932 も指定可） |
| `--format json` | 結果を JSON で出力する |

## 注意点

- キーが重複している行があると、比較を中止してエラーを返します。重複している行番号を表示するので、元データを確認してください。
- ファイル全体をメモリに読み込むため、数GBを超えるファイルには向きません。
