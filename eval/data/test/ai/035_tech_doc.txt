## 環境変数

アプリは起動時に次の環境変数を読みます。ローカルでは `.env.example` を `.env` にコピーして値を埋めてください。

| 変数名 | 必須 | 説明 |
|---|---|---|
| `DATABASE_URL` | ○ | PostgreSQL の接続文字列 |
| `REDIS_URL` | ○ | ジョブキューに使う Redis の接続先 |
| `SESSION_SECRET` | ○ | セッションの署名に使う32文字以上のランダムな文字列 |
| `MAIL_FROM` | | 送信元メールアドレス。未設定時は `no-reply@localhost` |
| `STORAGE_BUCKET` | | 添付ファイルの保存先。未設定時はローカルの `./tmp/uploads` に保存 |
| `LOG_LEVEL` | | `debug` / `info` / `warn` / `error`。既定は `info` |

必須の変数が1つでも欠けていると、起動時にどの変数が足りないかを表示して終了します。

`SESSION_SECRET` を変更すると、ログイン中のユーザーは全員ログアウトされます。本番で変更するときは、利用の少ない時間帯に行ってください。

ステージングと本番の値は、リポジトリには置かずシークレット管理サービスに登録しています。値を確認・変更するには、インフラ担当に権限を申請してください。
