# 評価データ

`<split>/<folder>/NNN_<surface>.txt` が1本1文書です。split は `dev`（規則づくり）・`tune`（1回目の test。不合格の分析に使ったため、閾値合わせに回した）・`test`（最終の未見データ）。

| folder | 中身 | 本数（dev / tune / test） |
|---|---|---|
| `human` | 人が書いた文（下の出典） | 20 / 40 / 40 |
| `ai_ish` | LLM に「生成AIが書きがちな典型的な書き方」で書かせた文。`meta.json` に意図した癖と強弱 | 20 / 40 / 40 |
| `ai` | LLM がふだんどおりに書いた文 | 20 / 40 / 40 |

## AI の文について

`ai_ish` と `ai` は、このプラグインの作成時に Anthropic の Claude（検出の規則を見せていない別の会話）が書いたものです。会社名・人名はすべて架空です。このリポジトリの他の部分と同じく MIT ライセンスで提供します。

`dev/ai/012_sns.txt` の絵文字1つ（走る人と女性の記号を結合子 U+200D でつないだもの）は、Hermes の security scan が見えない文字として警告するため、結合のない「走る人」の絵文字1字に置き換えています。
