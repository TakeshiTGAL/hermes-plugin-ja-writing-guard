# rewrite-ja: AI っぽい日本語を、意味を変えずに直す

この手順は nanaism/yomiyasu の「意味の保持」と「文書の立場と文末」、coji/natural-japanese の「検出は機械、判断はAI」「一律に直さない」の考え方を下敷きにしています（どちらも MIT。帰属は NOTICE）。

## 1. まず測る

`ja_writing_check` に本文と場面（surface）を渡します。場面は行き先で決めます。

| surface | 行き先 | 文体 |
|---|---|---|
| business_email | 社内外の業務メール | です・ます必須。Markdown と絵文字は使わない |
| external | お知らせ・リリース・サービス案内 | です・ます必須。宣伝調の言葉に厳しい |
| sns | X・note などの投稿 | くだけてよい。絵文字・感嘆符は可 |
| tech_doc | README・設計メモ・手順書 | 見出し・箇条書き・コードは可 |
| chat | チャットの返答 | 常体可。前置きと締めの決まり文句に厳しい |

結果の `findings` が直す候補です。`verdict` が `ok` なら直さずに出してかまいません。

## 2. 直す前に、変えてはいけないものを決める

書き直す前に、元の文の次の4点を確かめ、書き直した後も同じに保ちます。

1. 主張: 何を言っているか。論点を別の概念にすり替えない。
2. 比重: 何を一番大事とし、何を軽く扱っているか。否定していたものを並列にしない。
3. 言い切りの強さ: 断定は断定のまま、推量は推量のまま。「〜と言えるでしょう」を外すときに、強さを上げも下げもしない。
4. 文の働き: 説明・依頼・予定・評価の区別。評価の文を目標の文に変えない。

足さないことも同じくらい大事です。元の文にない事実・数字・例・理由・人名を書きません。分からないことは、本文で補わずに「確かめたい点」として最後に1行で聞きます。

## 3. 直す（指摘された箇所だけ）

- 定型句（「〜と言えるでしょう」「いかがでしたか」「お役に立てれば幸いです」）は削るか言い切る。評価を担っている「重要なのは」は述語に移して残す（「〜が大事です」）。
- 誇張・空虚な言葉（「シームレスに」「新たな価値」「重要な役割を果たします」）は、元の文にある事実で言い直す。事実がなければ削る。
- 直訳調（「〜することができます」「〜という観点から」「〜を持つ」）は日本語の形にする（「使えます」「〜で見ると」「〜がある」）。
- 記号: 語と語の間の「——」は読点か括弧にする。メール・社外文では太字・見出し・絵文字を外す。
- 文末: 同じ形が4回以上続くときだけ変える。文書の立場（勧め・決まり・説明）を先に決め、立場に合わない文末だけを直す。自然な文の文末をいじらない。
- 「AではなくB」は誤解を正しているなら残す。
- 箇条書き: 手順や本当に並列な情報はそのまま。考えのつながりを細切れにした箇条書きだけを地の文にする。

一律に全部を直さないでください。指摘のない文はそのまま残します。

## 4. もう一度測る

直した文を `ja_writing_check` に通し、点数が下がったこと、数字・固有名詞・URL・コードが元のままであることを確かめます。修正は2回までにし、点数を下げるためだけの言い換えを繰り返しません。

## 例

点数は同梱の検査で実測した値です。

元の文（社外向けのお知らせ, score 93）:

> 平素より格別のご高配を賜り、厚く御礼申し上げます。このたび、当社は新サービス「ミドリ便」をリリースいたしました。本サービスは、配送業務をシームレスに効率化し、お客様のビジネスに新たな価値を提供します。物流の未来を切り拓く第一歩として、ぜひご活用ください。

直した文（score 0）:

> 平素より格別のご高配を賜り、厚く御礼申し上げます。当社は新サービス「ミドリ便」の提供を始めました。配送業務の手間を減らすためのサービスです。ご利用をお待ちしております。

「シームレスに」「新たな価値」「未来を切り拓く第一歩」は中身のない言葉なので削り、元の文にある事実（配送業務の効率化）だけを残しました。どの作業がどれだけ楽になるのかは元の文にないため、書き足さずに書き手へ確かめます。

元の文（チャット, score 96）:

> 素晴らしい質問ですね！結論から言うと、毎日少しずつ続けることが非常に重要です。まず最初に、1日15分の時間を確保しましょう。いかがでしたか？お役に立てれば幸いです。

直した文（score 0）:

> 毎日少しずつ続けることが大事です。最初は1日15分の時間を確保しましょう。
